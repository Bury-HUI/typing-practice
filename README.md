# 打字练习 · 小游戏

一个零依赖的单文件打字练习网站，支持中文与英文，包含练习模式和三个打字小游戏。

## 功能

### 练习模式
- 语言：英文 / 中文 / 中英混合
- 时长：15 秒 / 30 秒 / 60 秒 / 不限时
- 实时统计：速度（英文 WPM、中文 字/分）、正确率、错误数、进度
- 逐字符着色反馈，正确/错误/当前位置一目了然，自动跟随滚动
- 中文输入法友好：组字期间不判定，只统计实际上屏的汉字
- 按「语言 + 时长」分别记录个人最佳成绩

### 小游戏
| 游戏 | 玩法 |
| --- | --- |
| 单词雨 | 词条从上方落下，落到底线前打出整词即可击落；3 点生命，漏词扣命，每击落 5 个升一关并加速 |
| 极速冲刺 | 30 秒内连续打词，打对立刻换下一个，打错清空连击 |
| 打字赛车 | 与电脑竞速打完一段文字，对手手速三档可选，打错不前进 |

三个游戏均跟随语言设置切换中英文词库，并按游戏记录最佳成绩。

## 使用

直接双击 `index.html` 用浏览器打开即可，无需安装、无需联网、无需构建。

也可以部署到任意静态托管（GitHub Pages、Netlify、Vercel 等），把 `index.html` 放到站点根目录即可。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，单文件，零依赖
- 输入采用透明输入框承接，配合 `compositionstart/update/end` 事件处理中文输入法，
  仅在汉字上屏后参与判定
- 游戏由单个 `requestAnimationFrame` 循环驱动，每帧 `dt` 上限 50ms，切换标签页回来不会跳帧
- 深浅主题、最佳成绩保存在浏览器 `localStorage`

## 浏览器支持

Chrome / Edge / Firefox / Safari 等现代浏览器。移动端可正常使用，但游戏需要实体键盘体验更好。
